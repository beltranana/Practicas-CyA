# Práctica 1 - Contenedores en C++

Este proyecto implementa un contenedor dinámico de enteros con capacidad
expandible, operaciones de inserción, eliminación, consulta, cambio y
visualización de contenido.

Compilar:
  make

Ejecutar:
  ./contenedor

Limpiar:
  make clean
